# 🐱 猫猫备忘录 · 四象限时间管理系统

> 一款以"艾森豪威尔四象限法则"为核心、**零安装、零后端、数据完全本地存储**的单人待办管理 Web 应用。以"猫猫陪伴"为产品主题，内置 100 个成就、十余种隐藏彩蛋与拟人化反馈，把枯燥的 DDL 管理变成有正反馈的日常习惯。
>
> 关键词：`原生 JavaScript` `四象限时间管理` `localStorage 持久化` `Chart.js 数据可视化` `游戏化设计` `响应式单页应用`

---

## 一、项目背景 & 目标

学生和职场新人的待办清单普遍存在三个痛点：任务只罗列不分类、DDL 靠脑子记、工具太"冷"难以坚持使用。

本项目希望解决：

1. **任务分类决策**——按"重要 / 紧急"两个维度自动归入四象限，明确"先做什么、少做什么"；
2. **DDL 紧迫感量化**——每个任务实时倒计时（精确到秒），并用进度条颜色（绿 → 橙 → 黄 → 红）直观呈现紧急程度，临期自动分级预警；
3. **坚持使用的动力**——用成就系统、隐藏彩蛋、每日寄语、拟猫化文案等游戏化手段提供持续正反馈，让时间管理工具本身"愿意被打开"。

## 二、快速开始

**方式一（推荐）**：直接双击 `index.html`，用任意现代浏览器（Chrome / Edge / Firefox / Safari）打开即可使用，无需安装任何环境。

**方式二**：在项目目录启动任意静态服务器后访问，例如：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> ⚠️ 页面通过 CDN 引入 **Chart.js**（统计图表）与 **lunar-javascript**（农历节日判定），首次使用建议联网；离线状态下任务管理等核心功能不受影响，仅图表与农历彩蛋不可用。

## 三、核心功能

### 1. 四象限任务管理

| 象限 | 含义 | 处理原则 |
|---|---|---|
| 🔴 Q1 重要且紧急 | 马上要交的作业、突发任务 | 立即执行 |
| 🔵 Q2 重要但不紧急 | 长期规划、能力提升 | 计划投入（重心） |
| 🟡 Q3 紧急但不重要 | 他人打扰、例行琐事 | 授权/快速处理 |
| ⚫ Q4 不重要不紧急 | 消遣类事项 | 尽量少做 |

- **引导式录入**：弹窗分步引导填写内容 → 象限 → 优先级（高/中/低）→ DDL，降低使用门槛；
- **拖拽改象限**：任务卡片支持 HTML5 拖放，跨象限拖动即可重新归类；
- **任务全生命周期管理**：标记完成、修改 DDL、修改内容/类型/优先级，已完成任务单独归档。

### 2. DDL 实时追踪与分级预警

- 每张任务卡片显示"剩余 X 天 X 时 X 分 X 秒"，**每秒刷新**；
- 进度条颜色随剩余时间自动变化（绿/橙/黄/红），已过期任务红色高亮；
- 系统自动检测 **DDL 过半、12 小时内临期、已过期** 三档状态，页面顶部给出黄/橙/红分级横幅提醒；
- 页面切到后台时自动暂停定时器，切回自动恢复，兼顾性能与电量。

### 3. 工作日志系统

- 添加 / 完成 / 修改 / 过期等操作自动写入系统日志，也可手动补充日志条目，支持编辑与删除；
- 日志导出为带时间戳的 `.txt` 文件（文件名含日期），支持**按选定日期范围导出**、导出全部、每日首次打开自动导出；
- 清空日志需二次确认，防止误操作。

### 4. 数据统计与可视化（Chart.js）

- 顶部卡片汇总：总任务数、已完成、过期任务、DDL 过半任务；
- **饼图**：四个象限的任务分布，检查精力分配是否合理；
- **柱状图**：按 DDL 紧急程度分五档（已过期 / 12 小时内 / 1 天内 / 1-3 天 / 3 天以上）统计任务量。

## 四、趣味化设计（本项目的特色）

- 🏆 **100 个成就**：覆盖任务量、连续使用、四象限分布、早鸟/夜猫子、周末劳模、DDL 冲刺、日志习惯、主题探索等，成就面板实时展示解锁进度；
- 🎉 **隐藏彩蛋系统**：互动达到 100 / 500 / 1000 次、四象限任务均衡、探索完全部功能、特定任务/日志里程碑等场景触发专属弹窗；
- 🎂 **生日惊喜**：生日当天打开自动触发烟花动画 + 猫猫手写信；
- 🥮 **节日问候**：内置公历节日（元旦、情人节、愚人节、国庆），并借助 lunar-javascript 自动判定春节、元宵、端午、中秋等**农历节日**；
- 🎨 **4 套主题 + 深夜模式**：默认 / 粉 / 蓝 / 紫主题，长按标题即可切换（兼容手机长按与电脑长按）；深夜使用时自动关怀提示并可一键进入夜间配色；
- 💌 **每日一句**：寄语池打乱后每天展示一条，附猫猫时间管理小贴士；
- 🐾 **细节反馈**：点击页面任意位置留下猫爪印动画、添加/完成任务有随机拟猫化回复、周末横幅、闲置"摸鱼"提醒；
- 📮 **问题反馈入口**：内置反馈问卷跳转入口，形成"用户反馈 → 迭代"闭环。

## 五、技术栈与实现

- **HTML5 + CSS3 + 原生 JavaScript（ES6）**：单文件实现，无任何前端框架与构建步骤，约 2500 行；
- **CSS 变量主题系统**：通过 `:root` 与 body 主题类切换整套配色，配合过渡动画；
- **localStorage 持久化**：任务、日志、成就、主题、连续使用天数、彩蛋记录等状态全部自动保存，刷新/关闭浏览器不丢失；
- **Chart.js（CDN）**：象限分布饼图与 DDL 紧急度柱状图；
- **lunar-javascript（CDN）**：公历日期实时转农历，判定传统节日；
- **Blob + URL.createObjectURL**：纯前端生成并下载日志文件；
- **响应式布局**：`viewport` 适配 + Grid 弹性菜单 + 触摸事件支持，手机与电脑浏览器均可使用。

## 六、数据与隐私说明

- 本应用**没有服务器、没有注册登录、不收集任何数据**，所有任务与日志仅保存在使用者浏览器的 localStorage 中；
- 更换浏览器或清理浏览器数据会导致记录丢失，重要日志请使用"导出日志"功能保存为本地 `.txt` 文件；
- 关键存储键：`tasks`（待办任务）、`finishedTasks`（已完成归档）、`logs`（工作日志）、`unlockedAchievements`（成就）、`currentTheme`（主题）等。
